# RandomBox 🎲

RandomBox का पहला MVP — एक random-content website।

## अभी क्या है
- Randomize button
- Categories
- Copy button
- Responsive/mobile UI
- Admin page से content add/delete
- Browser localStorage में data

## महत्वपूर्ण
यह MVP अभी **localStorage** इस्तेमाल करता है। यानी Admin में किए गए changes उसी browser/device पर save होते हैं।
सार्वजनिक online admin और multi-device updates के लिए अगले चरण में इसे आपके अपने database (जैसे Supabase) से जोड़ना चाहिए।

## Run
किसी भी static hosting पर index.html खोलें। Local testing के लिए VS Code + Live Server या कोई simple static server इस्तेमाल कर सकते हैं।
